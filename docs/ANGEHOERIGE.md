# FrischStart — Kurzanleitung für Angehörige

## Was passiert?

Windows startet aus einer geschützten VHD. Nach dem Neustart ist das System wieder
sauber — Viren und Fehlinstallationen sind weg.

## Vor dem Start

1. Backup / Systemabbild machen.
2. Externe Festplatte für Fotos & Dokumente bereithalten.
3. Zuerst in einer **Test-VM** üben.

## Einrichtung

1. `FrischStart.exe` **als Administrator** starten.
2. **„Installation starten (Assistent)“**
3. Weg wählen: bestehendes Windows übernehmen **oder** Neuinstallation in VHD.
4. Speicherort mit genug Platz wählen.
5. **Startreihenfolge** wählen (empfohlen: Menü 5 Sekunden).
6. Assistenten zu Ende führen → neu starten.

Details: [VHD-SETUP.md](VHD-SETUP.md) · Admin/Dump: [ADMIN-ZUGRIFF.md](ADMIN-ZUGRIFF.md)

## Was dem Senior sagen?

> „Wenn der PC komisch ist: **neu starten.** Dann ist er wieder sauber.“

## Dateien speichern

| Ort | Bleibt nach Neustart? |
|-----|------------------------|
| System / C: in der geschützten VHD | Nein |
| Externe Festplatte | Ja |
| Facebook-/Online-Spiele (Cloud) | Ja (am Account) |

## Dump ändern / Programme dauerhaft installieren

Beim Start (wenn Menü aktiv) **„FrischStart Wartung“** wählen.  
Oder: Shift + Neu starten. Siehe [ADMIN-ZUGRIFF.md](ADMIN-ZUGRIFF.md).
