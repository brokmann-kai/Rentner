# FrischStart — Kurzanleitung für Angehörige

## Was passiert?

Der PC wird so eingerichtet, dass **alles auf der Systemplatte nach einem Neustart
wieder verschwindet**. So sind Viren und versehentliche Installationen meist nach
einem Neustart weg.

## Vor dem Start

1. Windows-Backup oder Systemabbild machen.
2. Eine **externe Festplatte** anschließen (NTFS), z. B. als `D:`.
3. Wichtige Dinge dorthin kopieren: Fotos, Briefe, Steuerunterlagen.
4. Am besten zuerst in einer **Test-VM** üben.

## Einrichtung (Zielbild)

1. FrischStart **als Administrator** starten.
2. Testmodus aktivieren lassen (einmalig, mit Neustart).
3. Schutz nur für **C:** einschalten.
4. Externe Platte **nicht** schützen.
5. Nochmal neu starten — Schutz ist aktiv.

## Was dem Senior sagen?

> „Wenn der PC komisch ist oder etwas Falsches installiert wurde:  
> **ausknipsen und neu starten.** Dann ist er wieder sauber.“

## Dateien speichern

| Ort | Bleibt nach Neustart? |
|-----|------------------------|
| Desktop / Downloads auf C: | Nein |
| Externe Festplatte (ungeschützt) | Ja |
| Facebook-/Online-Spiele (Cloud) | Ja (am Account) |

## Schutz später ausschalten

Nur über FrischStart → „Schutz ausschalten“ → neu starten.  
Nicht die versteckte Datei `_qh_protect_state.data` von Hand löschen.
